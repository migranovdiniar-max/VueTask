# Vehicles SPA

SPA-приложение на Vue 3 + TypeScript для просмотра, сортировки, редактирования и удаления автомобилей, полученных через REST API. Дополнительно реализовано отображение автомобилей на карте (Yandex Maps).

---

## Технологии

- Vue 3 (Composition API)
- TypeScript
- Vite
- Pinia
- Axios
- Yandex Maps JavaScript API 2.1

---

## Функциональность

- Загрузка списка автомобилей с REST API
- Отображение таблицы (название, модель, год, цена)
- Сортировка по:
  - году
  - цене
- Создание автомобиля
- Редактирование автомобиля (название, модель, год, цена)
- Удаление автомобиля
- Отображение автомобилей на карте по координатам (latitude, longitude)
- Inline-редактирование
- Адаптивный интерфейс

---

## API

Используется внешний REST endpoint:

GET https://task.tspb.su/test-task/vehicles

Если сервер не поддерживает PATCH/DELETE, используется локальное обновление состояния через Pinia.

---

## Запуск проекта

### 1. Установка зависимостей

npm install

### 2. Создать файл `.env.local`

В корне проекта:

VITE_YANDEX_MAPS_API_KEY=your_api_key_here

### 3. Запуск dev-сервера

npm run dev

Приложение будет доступно по адресу:

http://localhost:5173

## Архитектура

- API слой вынесен отдельно
- Централизованное управление состоянием через Pinia
- Компоненты разделены по ответственности:
  - Form — создание
  - Table — просмотр, сортировка, редактирование
  - Map — отображение координат
- Типизация данных через отдельные интерфейсы
- API-ключ карты хранится в переменных окружения
